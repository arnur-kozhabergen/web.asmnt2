# Assignment 2 — Flexbox and Grid

A small website made with HTML and CSS for Web Technologies.

Live site: https://arnur-kozhabergen.github.io/web.asmnt2/

## Pages

- `index.html` — navigation bar and three Flexbox cards
- `layout.html` — page layout with Grid areas
- `gallery.html` — nine images in a Grid gallery
- `portfolio.html` — portfolio page using Grid and Flexbox

## How to open

Open `index.html` in a browser and use the navigation bar to visit the other pages. No installation is needed.

All photos are in the `images` folder.
